ArduPilot 최신 HW 구성도

Cube Orange+ 기준 · 2025–2026 일반적인 상용/연구용 구성 · Sensor Sampling 중심

이 문서는 무엇을 보여주나요? 드론(또는 무인기)의 “뇌” 역할을 하는 비행 제어기(Flight Controller)인 Cube Orange+를 중심으로, 어떤 센서·통신·전원·모터 장비가 붙는지 한눈에 보는 그림입니다. 아래 구성도 색은 기능 역할별로 나눴고, 연결 선 스타일/라벨로 통신 방식(프로토콜)을 구분합니다. 처음 보는 용어는 페이지 하단 용어 사전에서 설명합니다.
구성도 색 = 기능 역할 (비슷한 색을 피함)
Cube Orange+ (비행 제어기)
DroneCAN 항법·시야 센서
Rangefinder (거리 센서)
ADS-B (항공 교통 수신)
RC Receiver (조종 수신기)
Telemetry (원격 통신)
HereLink / GCS
Power (전원)
ESC / Motors / Servos
Companion / Safety

이전에는 Rangefinder와 RC Receiver가 둘 다 “Serial(시안)”로 묶여 같은 색이었습니다. 통신 방식이 비슷해도 역할이 다르므로 지금은 Rangefinder=노랑, RC Receiver=빨강으로 분리했습니다.

역할별 요약

Internal Cube Orange+ 센서

  • 삼중 IMU (가속도+자이로) — 내부 SPI, 고속 샘플 1~8 kHz
  • 기압계 2개 (Barometer) — 고도 추정
  • 자기계 (Magnetometer) — 방위(나침반) 보조
  • 온도 제어 + 진동 격리 (일부 IMU)
  • Failsafe Co-processor — 메인 CPU 이상 시 안전 보조

DroneCAN 권장 센서

  • Here4 — 정밀 위성 위치(RTK GNSS) + IMU + Mag
  • Optical Flow — 지면 패턴으로 수평 이동 추정
  • 외부 RM3100 나침반 (전자 노이즈 회피용)
  • 일부 Lidar / 대기속도(Airspeed) 센서
  • 한 버스에 여러 장치 · 배선 단순

RC · 거리 · 통신

  • RC Receiver — 조종기 스틱 입력을 FC로 (RCIN)
  • Rangefinder — 지면/장애물까지 거리 (고도 보조·착륙)
  • Telemetry — 지상과 상태·명령 교환 (TELEM)
  • ADS-B In — 주변 항공기 위치 수신 (충돌 인지)
  • HereLink / GCS — 조종·영상·데이터 통합 지상 장비

Actuator · Power

  • MAIN OUT — ESC로 모터 추력 명령 (PWM/DShot)
  • ESC — 배터리 고전류를 모터에 맞게 제어
  • Servos — 고정익 조종면, 짐벌 등 (선택)
  • Power Module — 전압·전류 측정 후 FC에 전달
  • Companion — 비전/AI용 보조 컴퓨터 (MAVLink)

용어 사전 (처음 나오는 말부터)

구성도와 카드에 나온 말을 초보자 기준으로 짧게 풀어 씁니다. 이미 아는 항목은 건너뛰셔도 됩니다.

1. 전체 시스템
ArduPilot 아두파일럿
드론·자동차·보트 등 무인 플랫폼용 오픈소스 자동 조종 소프트웨어입니다. 이 문서의 “뇌” 소프트웨어 이름입니다.
HW 구성도 Hardware
Hardware(하드웨어)의 약자입니다. 소프트웨어가 아니라 실제 보드·센서·배선·모터 같은 물리 부품 연결 관계를 그린 그림입니다.
Flight Controller (FC) 비행 제어기
센서 데이터를 읽고, 자세·위치를 계산하고, 모터에 명령을 보내는 중앙 보드입니다. 여기선 Cube Orange+가 FC입니다.
Cube Orange+
CubePilot의 고급 비행 제어기 모델입니다. 고성능 MCU와 여러 개의 여분(redundant) 센서를 넣어 상용·연구용에 자주 쓰입니다.
STM32H757 · 400 MHz
STMicroelectronics의 32비트 마이크로컨트롤러(작은 컴퓨터 칩) 이름입니다. 약 400 MHz로 동작하며, ArduPilot이 돌아가는 “CPU” 역할을 합니다.
Sensor Sampling 센서 샘플링
센서가 측정값을 얼마나 자주 읽는지(초당 횟수)를 말합니다. 단위는 보통 Hz(1초에 N번) 또는 kHz(1초에 N×1000번)입니다.
Hz / kHz
주파수 단위. 50 Hz = 1초에 50번 갱신. 1 kHz = 1초에 1000번. IMU는 수천 Hz, GPS는 보통 5~20 Hz처럼 센서마다 다릅니다.
2. Cube 내부 센서
IMU Inertial Measurement Unit · 관성 측정 장치
가속도계(Accel)와 자이로스코프(Gyro)를 묶어 부르는 말입니다. “지금 얼마나 기울고, 얼마나 회전·가속하는지”를 측정합니다. 자세 제어의 핵심입니다.
Triple Redundant IMU 삼중 여분 IMU
IMU를 3세트 넣어, 하나가 고장·이상해도 나머지로 비행을 이어가려는 설계입니다. Redundant = 여분·이중화.
ICM42688 / ICM20948
실제 IMU 칩 모델명(제조사 부품 번호)입니다. 구성도에 “어떤 센서가 들어 있는지”를 구체화한 표기입니다.
Accel / Gyro 가속도계 / 자이로
Accel은 직선 가속·중력 방향, Gyro는 각속도(회전 속도)를 측정합니다. 둘을 합쳐 기체의 자세를 추정합니다.
Baro / Barometer 기압계
대기 압력으로 대략적인 고도를 추정합니다. GPS 고도보다 짧은 구간 반응에 자주 쓰이며, Cube에는 보통 2개가 있습니다(MS5611 등).
Mag / Magnetometer 자기계 · 나침반
지구 자기장을 읽어 방위(어느 쪽이 북쪽인지)를 돕습니다. 모터·전원 배선 근처 전자 노이즈에 약해, 외장 Mag를 쓰기도 합니다.
Temp Control 온도 제어
IMU 온도를 일정 범위로 유지해 온도 변화에 따른 센서 오차를 줄이는 기능입니다.
SPI Serial Peripheral Interface
보드 안에서 칩끼리 고속으로 데이터를 주고받는 연결 방식입니다. Cube 내부 IMU는 SPI로 매우 빠르게 샘플링합니다.
Failsafe Co-processor (F103)
메인 프로세서와 별도인 작은 보조 CPU입니다. 메인 쪽이 멈추거나 이상할 때 모터 안전 차단 등 failsafe(비상 안전) 동작을 돕습니다. F103은 그 칩 계열 이름입니다.
3. 항법·시야 센서 (주로 DroneCAN)
DroneCAN
드론용 CAN 버스 프로토콜입니다. 전원·데이터 선을 공유하는 버스에 GPS, 나침반, 광학 플로우 등을 여러 개 달 수 있어 배선이 단순해집니다. 구성도에서 보라색 점선 쪽입니다.
CAN / CAN1 / CAN2
Controller Area Network. 자동차·산업에서 쓰는 견고한 통신 버스입니다. Cube에는 CAN 포트가 여러 개 있어 장치를 나눌 수 있습니다.
GNSS / GPS 위성 항법
인공위성 신호로 위치·속도를 구하는 시스템입니다. GPS는 미국 시스템 이름이고, GNSS는 GPS·Galileo·BeiDou 등을 아우르는 더 넓은 말입니다.
Here4
CubePilot 계열의 고급 GNSS 모듈 제품명입니다. 멀티밴드 RTK, 자체 IMU, 고정밀 나침반(RM3100) 등을 묶어 DroneCAN으로 연결하는 구성이 흔합니다.
Multiband 멀티밴드
위성 신호의 여러 주파수 대역을 동시에 받는다는 뜻입니다. 단일 대역보다 오차·간섭에 강한 편입니다.
RTK Real-Time Kinematic
지상 기준국(또는 네트워크) 보정을 더해 GNSS 위치를 센티미터 급으로 정밀하게 만드는 기술입니다. 측량·정밀 착륙·연구용에 많이 씁니다.
F9P
u-blox의 고정밀 GNSS 수신 칩/모듈 시리즈 이름입니다. RTK를 지원하는 제품에 자주 들어갑니다.
RM3100
고정밀 자기계(나침반) 센서 모델입니다. 드론 동체 자기 간섭을 피하려고 GPS 모듈이나 외장 막대에 달아 쓰는 경우가 많습니다.
Optical Flow 광학 플로우
아래를 보는 카메라로 지면 무늬의 움직임을 읽어, GPS 없이도 수평 이동을 추정합니다. 실내·저고도 호버에 유리합니다. HereFlow, ARK Flow 등이 제품 예입니다.
TOF Time of Flight
빛(또는 신호)이 갔다 오는 시간으로 거리를 재는 방식입니다. 짧은 거리 고도·근접 감지에 쓰입니다.
Lidar 라이더
레이저로 거리를 재는 센서입니다. 고도, 장애물, 지형 추적 등에 사용합니다. (레이더와 이름만 비슷하고 원리는 다릅니다.)
I2C
보드/센서 간 저속 직렬 통신 방식 중 하나입니다. 일부 나침반·소형 센서가 I2C로 연결됩니다. DroneCAN보다 거리·다중 장치에 약합니다.
Airspeed 센서 대기속도
공기가 부딪히는 압력으로 “공기에 대한 속도”를 재는 센서입니다. 고정익(비행기형)에서 실속 방지·항법 정확도에 중요합니다. 멀티콥터에는 없는 경우가 많습니다.
4. 거리·교통·조종 입력 (색이 서로 다름)
Rangefinder 거리 센서 · 구성도 노랑
기체에서 지면 또는 물체까지 거리를 잽니다. 정밀 고도 유지, 착륙, 장애물 회피에 씁니다. Lightware, Benewake(TF-Luna 등), SF45 같은 제품이 예입니다. Serial 또는 CAN으로 연결됩니다.
RC Receiver RC 수신기 · 구성도 빨강
RC = Radio Control. 조종기(송신기) 전파를 받아 스로틀·롤·피치·요 등 채널 값을 FC에 넘깁니다. Rangefinder와 역할이 전혀 다릅니다(거리는 센서, RC는 조종 입력).
RCIN
비행 제어기의 “RC 입력” 포트 이름입니다. 수신기 신호를 꽂는 자리로 이해하면 됩니다.
SBUS / CRSF / DSM
수신기와 FC 사이 디지털 신호 규격 이름입니다. SBUS(Futaba 계열 등), CRSF(ExpressLRS/TBS 등), DSM(Spektrum 등)처럼 브랜드·프로토콜이 다릅니다. 수신기·송신기 짝이 맞아야 합니다.
ADS-B In
Automatic Dependent Surveillance–Broadcast. 주변 유인/무인 항공기가 방송하는 위치 신호를 수신해 “근처에 누가 있는지”를 알 수 있게 합니다. In = 수신 전용. uAvionix 등이 대표 제품군입니다.
Serial / UART
선 몇 개로 한 장치와 1:1에 가깝게 글자(바이트)를 주고받는 기본 직렬 통신입니다. 텔레메트리, 일부 GPS, 거리 센서, 보조 컴퓨터 연결에 흔합니다. “Serial 5”는 보드의 5번 시리얼 포트를 가리킵니다.
5. 지상 통신·지상국
Telemetry 텔레메트리 · 구성도 청록
기체 상태(자세, GPS, 배터리, 모드 등)를 지상으로 보내고, 지상에서 명령·미션을 올리는 양방향 데이터 링크입니다. 영상(비디오)과는 별개인 경우가 많습니다.
TELEM1 / TELEM2
Cube 캐리어보드에 있는 텔레메트리용 시리얼 포트 이름입니다. 보통 TELEM1에 장거리 라디오를 연결합니다.
RFD900x / SiK / LTE
텔레메트리 라디오 예시입니다. RFD900x는 장거리 전용 모듈, SiK는 오픈 텔레메트리 펌웨어 계열 라디오, LTE는 휴대폰 망을 쓰는 링크입니다.
GCS Ground Control Station · 지상 통제국
노트북·태블릿에서 지도를 보고 미션을 짜고, 비행 상태를 감시하는 소프트웨어/장비입니다. Mission Planner, QGroundControl 등이 대표적입니다.
HereLink
조종 스틱 + 화면 + 영상/데이터 링크를 한 세트로 묶은 통합 컨트롤러 제품군입니다. 전통적인 “조종기 + 별도 텔레메트리 + 별도 영상”을 합친 형태에 가깝습니다.
MAVLink
ArduPilot·PX4 생태계에서 쓰는 메시지 프로토콜입니다. FC ↔ GCS, FC ↔ Companion Computer 사이에 “지금 자세는…”, “이 웨이포인트로…” 같은 명령을 표준 형식으로 주고받습니다.
6. 전원·구동계
Power Module 전원 모듈
배터리에서 오는 고전압·고전류를 측정하고, FC가 쓸 수 있는 전원도 나눠 주는 모듈입니다. 전압(V)과 전류(A) 피드백으로 남은 용량·과전류를 감시합니다. Mauch, Holybro 등이 유명합니다.
POWER1 / POWER2
Cube에 전원 모듈을 꽂는 커넥터 이름입니다. 이중 전원 입력으로 redundancy를 주는 구성도 있습니다.
LiPo / Li-Ion 리튬 폴리머 / 리튬 이온
드론에 쓰는 충전 배터리 종류입니다. LiPo는 고출력에 강하고, 일부 장시간은 Li-Ion을 씁니다.
4S ~ 12S
S = Series(직렬 셀 개수). 4S는 셀 4개 직렬(공칭 약 14.8 V), 12S는 더 높은 전압입니다. 모터·ESC 정격과 반드시 맞춰야 합니다.
ESC Electronic Speed Controller · 전자 속도 제어기
FC의 “이만큼 돌려” 명령을 받아, 배터리 전력으로 브러시리스 모터 속도를 실제로 조절하는 장치입니다. 채널 수(4~8ch)는 모터 개수에 맞춥니다.
PWM Pulse Width Modulation
펄스 폭으로 값을 전달하는 고전적인 제어 신호입니다. ESC·서보에 널리 쓰이며, MAIN OUT 핀으로 나갑니다.
DShot
ESC용 디지털 프로토콜입니다. 아날로그 PWM보다 노이즈에 강하고, 양방향 텔레메트리(RPM 등)를 지원하는 변형도 있습니다.
MAIN OUT / AUX OUT
FC 캐리어보드의 출력 핀 그룹입니다. MAIN은 주로 모터(ESC), AUX는 서보·짐벌·추가 장치용으로 쓰는 구성이 흔합니다.
Motors · BLDC
BLDC = Brushless DC, 브러시 없는 직류 모터입니다. 드론 프로펠러를 돌리는 주 추력원입니다. T-Motor U/MN 등은 제품 시리즈 예입니다.
FOC Field Oriented Control
모터를 더 효율·정숙하게 제어하는 고급 ESC 제어 방식입니다. “FOC ESC”라고 적힌 제품이 이에 해당합니다.
Servos 서보
각도 위치를 제어하는 작은 액추에이터입니다. 고정익 조종면, 카메라 짐벌, 투하 장치 등에 쓰이며 멀티콥터 기본 구성에는 없을 수 있습니다.
Actuator 액추에이터
전기 신호를 “움직임”으로 바꾸는 장치 전반(모터, 서보 등)을 가리키는 말입니다.
7. 보조 컴퓨터·안전
Companion Computer 컴패니언 컴퓨터
FC 옆에 다는 소형 컴퓨터입니다. 카메라 AI, 경로 계획, ROS 등 무거운 계산을 맡고, 결과는 MAVLink로 FC에 전달합니다. Jetson, Raspberry Pi 5, Orin 등이 예입니다.
Jetson / RPi 5 / Orin
NVIDIA Jetson(Orin 포함)은 GPU 가속 AI에 강하고, Raspberry Pi 5는 범용 저전력 보드입니다. “어떤 보조 PC를 쓰는지” 예시 표기입니다.
Ethernet / UART
Companion과 FC를 잇는 물리 연결 예입니다. UART는 시리얼, Ethernet은 랜 케이블·네트워크로 더 높은 대역폭 통신에 씁니다.
Safety Switch 안전 스위치
모터가 돌 수 있는 상태(아밍)로 들어가기 전에 누르는 물리적 안전 장치입니다. 오작동으로 프로펠러가 갑자기 도는 것을 줄입니다.
Buzzer / LED
버저는 비프음으로 모드·오류·GPS 상태 등을 알리고, LED는 색·점멸로 상태를 표시합니다.
Arming / Failsafe 아밍 / 페일세이프
Arming은 “모터 출력을 허용”하는 단계입니다. Failsafe는 통신 두절·저전압 등 이상 시 RTL(귀환), 착륙, 모터 차단 같은 미리 정한 안전 동작입니다.
8. 파라미터·기타
INS_FAST_SAMPLE / GPS_RATE 등
ArduPilot 설정 파라미터 이름 예입니다. INS_FAST_SAMPLE은 IMU 고속 샘플링, GPS_RATE는 GNSS 갱신 주기 관련 설정입니다. 실제 샘플링은 파라미터 + 센서 능력에 따라 달라집니다.
Carrier Board 캐리어 보드
Cube “뇌” 모듈을 꽂는 하단 보드로, 여기에 TELEM, RCIN, POWER, MAIN OUT 같은 커넥터가 모여 있습니다. 문서의 포트 이름은 대개 캐리어 기준입니다.
Redundant / 이중화
같은 역할을 하는 부품을 둘 이상 두어, 하나가 실패해도 시스템이 버틸 여지를 두는 설계입니다. 삼중 IMU, 이중 전원 등이 해당합니다.
